## About Me

I'm a **Software and Game Development (PPLG / RPL)** student at SMK Negeri 4 Padalarang. My journey started in web development, where I built a foundation across frontend interfaces, backend services, relational databases, and REST APIs.

That same curiosity led me to game development, where programming meets interactive mechanics, systems design, and storytelling. My goal is to keep growing as a versatile developer who can build both reliable software products and engaging interactive worlds.

## Featured Projects

### [CritiPlay](https://github.com/SaktiArifDwiPutra/CritiPlay)
**Full-Stack · Game Discovery, Backlog Tracker & Review Platform**

A web application where gamers discover titles, organize their backlog, and write multi-aspect reviews. Built with a React and TypeScript SPA communicating with a Laravel REST API backed by Neon PostgreSQL.

- **Technical Focus:** Token authentication via Laravel Sanctum, Google OAuth via Socialite, IGDB/Twitch API game discovery, personal game libraries, user/public profiles, and Scalar OpenAPI documentation.
- **Stack:** <img src="https://skillicons.dev/icons?i=react,ts,vite,tailwind,laravel,postgres&theme=dark" alt="React, TypeScript, Vite, Tailwind CSS, Laravel, PostgreSQL" />
